# 📊 CSV to Summary via API Gateway (Base64 Upload Script)

This script allows you to upload a CSV file, encode it in Base64, send it to your deployed AWS API Gateway endpoint, and receive a summarized JSON response generated by an LLM-powered Lambda function. It also saves the payload to `body.json`.

---

## 🧠 How It Works

1. Takes a `.csv` file as input.
2. Converts the file contents into Base64.
3. Formats a request body that AWS Lambda (behind API Gateway) expects.
4. Sends a POST request to the `/summarize` API endpoint.
5. Displays the summarized result returned by the backend.

---

## 🚀 Prerequisites

- Python 3.7 or higher
- Internet access (to invoke API Gateway)
- Installed Python package: `requests`
